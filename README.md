📊 Stakeholder Insights & Performance Dashboard
🚀 Overview

This dashboard provides a comprehensive analytical view of business performance across stakeholders, insurers, and policy metrics. It helps users quickly interpret trends, evaluate profitability, and understand asset distribution — enabling data-driven decisions for insurance and finance operations.

🎯 Purpose

The dashboard is designed to deliver strategic insights by visualizing:

Premium trends over time

Value created by insurers

Profitability by city & policy tenure

Shareholder distribution

Asset allocation across stakeholders

Relationship between cost ratios & profitability

These insights help businesses improve performance, identify growth opportunities, and optimize decision-making.

📈 Key Features & Visualizations
1️⃣ Value Creation by Insurers

Comparative chart showcasing the total value created by each insurer.

Helps identify top-performers and underperforming areas.

2️⃣ Premium Over Time

Line/area trend visualization showing year-wise premium collection.

Enables time-series analysis for forecasting and performance review.

3️⃣ Shareholder Distribution

Pie/Bar visual representation of shareholding patterns (FIIs, DIIs, Retail, Promoters).

Helps understand ownership structure and investor diversity.

4️⃣ Profitability by City & Tenure

Heatmaps and bar charts showing policy profitability segmented by city and tenure duration.

Supports regional and demographic performance analysis.

5️⃣ Cost Ratio vs. Profitability

Correlation/Scatter charts to analyze how Opex, commission, and cost ratios affect profitability.

6️⃣ Assets Under Management (AUM)

Bar charts showing AUM distribution across stakeholders like customers, investors, communities, etc.

Highlights concentrations and growth potential.

🎛️ Filters for Dynamic Analysis

The dashboard supports extensive filtering options:

City Filter: View metrics for specific regions.

Stakeholder Filter: Analyze insurer or stakeholder contributions.

Policy Tenure Slider: Adjust tenure ranges for comparison.

Date Range Filter: Explore performance across specific periods.

Gender Filter: Provides demographic segmentation.

All charts automatically refresh based on the selected filters.

🧩 Interactivity

🔹 Click on charts to apply cross-filtering across visuals

🔹 Hover tooltips for detailed insights

🔹 Instant KPIs and visual updates when filters are applied

🔹 Dynamic drill-down analysis for deeper exploration

📄 Export Options

One-click Export to PDF button

Captures all charts, KPIs, and filters in the current dashboard state

Includes light company watermark for branding

PDF suitable for sharing, documentation, and presentations

🔐 Role-Based Access

The dashboard supports controlled data visibility:

Different user roles (admin, insurer, stakeholder, analyst) see different sets of data

Ensures data privacy and proper access management
